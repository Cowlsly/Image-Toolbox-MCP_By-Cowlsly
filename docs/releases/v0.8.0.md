# v0.8.0 — first phone-testable alpha (draft release notes)

> Draft for the owner to publish as a **pre-release** on GitHub (tag `v0.8.0` on `root`). Steps: [release-checklist.md](../release-checklist.md) §2.

A local MCP server that lets an AI assistant work on images in one folder you choose — inspect, convert, resize, compress, rotate/flip, crop and batch — without ever overwriting your originals. Independent project inspired by [Image Toolbox](https://github.com/T8RIN/ImageToolbox) by T8RIN (Apache-2.0); no upstream code is included.

## What's in it

- **7 tools:** `image_inspect`, `image_convert`, `image_resize`, `image_compress`, `image_rotate_flip`, `image_crop`, `image_batch`.
- **Safe by default:** reads only inside `--root`, writes only new files into the output folder (numbered names, never overwrite), strips EXIF/GPS from outputs, refuses symlinks and paths outside the folder, size/pixel limits, decoder allowlist (JPEG/MPO, PNG, WebP, GIF, TIFF, BMP). Threat model: `docs/threat-model.md`.
- **New in 0.8.0:** `imagetoolbox-mcp --self-test` — one command that checks an install end to end and prints PASS/FAIL lines; Termux install guide `docs/install-termux.md`.

## Install

```sh
pip install "git+https://github.com/Cowlsly/Image-Toolbox-MCP_By-Cowlsly@v0.8.0"
imagetoolbox-mcp --self-test
```

Android/Termux: follow `docs/install-termux.md`. Client setup (Claude Code / Gemini CLI in Termux, desktop clients): `docs/clients.md`.

## Known limitations

- Alpha. Tested in a Linux cloud sandbox (Python 3.13, Pillow 12.3, MCP SDK 2.3; 195 tests). **Not yet run on a phone**, and GitHub CI has not run yet.
- stdio only. The Claude and ChatGPT phone apps cannot connect (they need a public HTTPS server with OAuth — deferred, ADR-0003).
- No hard per-call timeout or parser sandbox yet (threat model R2); very large PNG conversions are slow on phones.
- No HEIC/AVIF input.
