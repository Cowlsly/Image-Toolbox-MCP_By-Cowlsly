# v0.9.0 — advanced tools, resumable batches, isolation

Pre-release. All tools run locally; nothing leaves your device.

## New
- `image_adjust`, `image_watermark`, `image_recipe`, `image_tag` (11 tools in total).
- `image_batch` can now `adjust` and `watermark`, resume from an earlier manifest (`resume_from`) and retry temporary failures (`retries`).
- `--isolate SECONDS`: each operation runs in a child process with a hard time limit.
- `--max-megapixels` for low-memory phones, `--log-format json`, `--sbom`.
- Files are opened with a confined walk from the input folder, so a folder swapped for a shortcut mid-call cannot redirect a read (Linux/Android/macOS).
